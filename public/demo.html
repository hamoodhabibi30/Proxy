📖 How to Use

Basic Usage

GET http://localhost:3000/proxy?url=<target_url>

Iframe Integration

<iframe src="http://localhost:3000/proxy?url=https://vidsrc.example.com/embed/movie123"></iframe>

API Usage

const response = await fetch('http://localhost:3000/proxy?url=https://example.com/embed');
const cleanContent = await response.text();

🔧 Configuration

The proxy can be configured via config.json to customize:

  • Ad Patterns: Domains and patterns to block
  • Custom Ads: Your own advertisement HTML content
  • Server Settings: Port, timeout, and other server options
